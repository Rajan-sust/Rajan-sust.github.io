  1. NLPJ
    Kingfisher: A hybrid LLM-augmented Bangla text normalization for enhanced text-to-speech
    Rajan Saha Raju, Arif Ahmad, and Mohammad Shahidur Rahman
    Natural Language Processing Journal, Feb 2026
    Abs Bib Code

    Kingfisher is a three-stage hybrid Bangla text normalization framework for Text-to-Speech, combining LLM-based tokenization and semiotic class annotation, lexicon-driven context-aware verbalization, and automated error correction. It achieves 96% overall accuracy (95% CI: 95-97%) across diverse Bangla texts, outperforming Sparrowhawk, the only previously available Bangla normalizer.

2025

  1. bioRxiv
    ProtSEC: Ultrafast Protein Sequence Embedding in Complex Space Using Fast Fourier Transform
    Rajan Saha Raju and Rashedul Islam
    bioRxiv, Oct 2025
    Abs Bib

    ProtSEC is a training-free protein sequence embedding method in complex space using Fast Fourier Transform (FFT). Unlike protein language models (ESM2, ProtBERT, ProtT5), which require GPUs for inference, ProtSEC generates embeddings on CPU with substantially lower runtime while exceeding their performance on sequence similarity search.

  2. Genomics
    VirusTaxo: Taxonomic classification of viruses from the genome sequence using k-mer enrichment
    Rajan Saha Raju, Abdullah Al Nahid, Preonath Chondrow Dev, and 1 more author
    Genomics, Jun 2022
    Abs Bib Code

    VirusTaxo is a dedicated virus classifier with  93% accuracy at the genus level across 682 viral genera. It outperformed existing tools in metagenomic benchmarks, accurately identified the taxonomy of the novel virus SARS-CoV-2 even when excluded from the database, and is released as an open-source framework accessible to the community.
