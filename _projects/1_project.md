Kingfisher is a three-stage hybrid Bangla text normalization framework for Text-to-Speech, combining LLM-based tokenization and semiotic class annotation, lexicon-driven context-aware verbalization, and automated error correction.

It achieves 96% overall accuracy (95% CI: 95-97%) across diverse Bangla texts, outperforming Sparrowhawk, the only previously available Bangla normalizer. Kingfisher is released together with the first public Bangla text normalization dataset.
